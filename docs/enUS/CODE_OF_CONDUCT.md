# Code of Conduct (English)

See the root [`CODE_OF_CONDUCT.md`](../../CODE_OF_CONDUCT.md) for the full text.

Summary: we pledge a harassment-free, welcoming, and inclusive community. Be
respectful of differing opinions, give and accept constructive feedback
gracefully, and take responsibility for mistakes. Harassment, insults, and other
unacceptable behavior are prohibited. Maintainers enforce these standards and
may remove or ban contributors who violate them. Report incidents through the
channels listed in the root document.
